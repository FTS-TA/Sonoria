Getting Started

1

Include the Library

Start by including the necessary Sonoria headers in your C++ project.

#include <sonoria/algorithm.h>
#include <sonoria/streaming/vectorinput.h>
#include <sonoria/streaming/vectoroutput.h>
2

Initialize an Algorithm

Create and configure audio analysis algorithms with your specific parameters.

auto mfcc = AlgorithmFactory::create("MFCC");
mfcc->configure("sampleRate", 44100);
3

Process Audio Data

Feed audio frames to the algorithm and retrieve computed features.

std::vector<Real> audioFrame = loadAudio();
std::vector<Real> mfccs;
mfcc->input("frame").set(audioFrame);
mfcc->compute();
mfcc->output("mfcc").get(mfccs);
